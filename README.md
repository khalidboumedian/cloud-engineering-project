# Cloud Infrastructure and DevOps Project

## Overview

A hands-on cloud engineering project focused on building,
automating, and operating AWS infrastructure using
Infrastructure as Code and DevOps practices.

## Technical Stack

- AWS
- Terraform
- Git and GitHub
- Python
- Linux and Bash
- Docker
- GitHub Actions (CI/CD)
- AWS monitoring and security services

## Learning Objectives

- Provision AWS infrastructure using Terraform.
- Apply cloud security and IAM best practices.
- Automate tasks with Python and Bash.
- Build automated validation and deployment workflows.
- Monitor, troubleshoot, and optimize cloud workloads.
- Document architecture and deployment procedures.

## Project Status

Phase 1: Environment setup and repository initialization.

## Security

should be committed to this repository.
